# RoboAVA-Luna

Aplicativo local em Python para automatizar tarefas no AVA, com interface gráfica, Playwright e integração com a API OpenAI.

## Tecnologias

- Python
- Playwright
- API OpenAI

## Segurança

Configure `OPENAI_API_KEY` no computador onde o programa será executado. Não coloque chaves ou senhas no código.

Consulte as instruções completas de instalação e uso neste README.
